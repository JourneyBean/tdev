# v0.0.3

`tdev setup` 改为连接向导，配合实时远端发现和本机端口偏好，减少首次连接与重复配置。

- 自动列出已有 tdev 服务器和 SSH Host，支持 Include 文件、搜索和直接添加 `user@host:port`。
- 连接后读取目标设备已有项目；保留现有连接、远端配置目录与本机偏好。远端缺少 tdev 时可确认安装官方签名版本。
- 零项目时直接引导创建；通过 `tdev create` 创建项目，`project list/show/update`、`project window` 与 `project forward` 经 SSH 管理远端项目定义。
- 直接 `tdev open` 打开尚未配置的项目时，可跟随向导填写远端目录，创建后继续进入工作区。
- 向导输入支持方向键编辑；远端目录支持 Tab 补全及多候选选择，兼容中文、空格和引号。
- 创建时未指定服务器会先提示选择；输入界面使用 Bubble Tea，候选菜单随终端尺寸调整，长目录名截断展示。
- 新增 `tdev completion bash/zsh`，支持命令、选项、服务器名及实时远端项目补全。
- 安装时可确认并自动配置补全，提供 `--completion all` 和独立 `completion install` 命令；保留原 shell 配置与备份，重复运行保持单一区块。
- 每次 `ls`、`open` 都读取远端最新定义，再合并本机 `overrides.yaml`；没有项目配置缓存。
- 向导可调整本机监听端口，也可使用 `tdev override` 查看、修改或重置。覆盖绑定项目 UUID 和稳定 forward ID，避免同名新项目继承旧设置。
- `forward --save` 保存本机 `-L` 偏好，`--save-remote` 显式保存共享定义。`save` 保存窗口时保持远端端口定义。
- `ls` 默认显示易读列表；`--json` 保留结构化输出并同时提供 `remote_project` 和合并后的 `project`。

```sh
tdev upgrade
tdev setup
tdev ls
tdev open my-awsome-project
```

旧版 `client.yaml` 保持兼容，本机 override 单独保存。旧客户端忽略该附加文件。
