# v0.3.0

新增 tmux 分屏布局保存与恢复，改进项目列表和诊断输出。

- `save` 保存横向、纵向及嵌套分屏、比例和各 pane 的目录，新建会话恢复布局。按稳定 pane ID 保留声明的启动命令，手动新增 pane 保存为空 shell。
- 窗口配置支持 `layout`，可通过 `edit --stdin` 设置；交互编辑保留已有分屏。单 pane 窗口继续使用原配置格式。
- 增加 `pane-layout-v1` 能力检查，携带分屏配置的远端写入会在服务端读取输入前验证兼容性。使用分屏配置的客户端和服务端均需支持该能力；布局比例按可用终端空间近似恢复。
- `ls` 使用 SERVER、NAME、TYPE、STATUS、DIR、FORWARDS 六列表格，支持中文对齐。端口映射以箭头展示，多条映射分行排列；映射 ID 可从 `show` 或 `override` 查看。
- 列表刷新完成后移除 syncing 提示，服务器错误及缓存时间集中展示。
- `doctor` 默认用中文概括检查结果，解释依赖缺失、会话警告、覆盖配置错误和连接失败的影响及处理建议；离线缓存单独说明，`--json` 保留结构化数据。
- 补充真实 SSH/tmux 分屏及诊断集成测试，并更新终端列表回归。

机器协议、配置 schema 均保持为 1，沿用现有安装签名公钥。已有运行中的会话继续使用当前布局，新建会话使用保存的分屏配置。
