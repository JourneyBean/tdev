# v0.1.0

项目成为默认操作对象，本机和远端使用同一套命令。

- local 是内置服务器，无需 setup。裸项目名先查本机，再按远端服务器名排序查找；完整标识 server/project 可明确目标。
- 移除默认服务器选择与存储，已有配置中的旧字段读取后丢弃。forward 保存统一使用 add/remove 和 override，纯数字参数作为项目名称。
- 移除 project/window 用户分组，提供顶层 create/show/edit。edit 与 create 共用目录、窗口和端口映射向导，保存前预览并检查 revision。
- 创建时支持连续添加 L/R 映射，直接输入 host:port。本机监听差异保存在客户端 override。
- ls 包含本机与全部远端，终端先展示临时缓存和 syncing，再并发刷新。离线保留带时间的快照，实际操作始终读取最新定义。
- 机器接口更名为 api，项目定义统一通过 project get/set 修改。版本查询、能力检查与独立操作用 shell 合并到同一次 SSH，通过随机标记和退出码分段解析。
- 旧服务端提示升级，原 local 协议入口移除。远端安装升级继续使用签名验证与候选程序引导。
- tmux session 优先使用项目名称，按 UUID 识别归属并复用旧会话。名称差异与同名普通会话显示 warning；open 保留普通会话并创建独立托管会话。
- 新项目默认窗口 main；sh --name 指定新窗口名称，默认 shell。
- open 默认只打开终端并建立转发，--mount 显式挂载。独立 mount/unmount 保留，挂载路径保存为本机 override，退出 open 后挂载保留。
- 单文件 push/pull 到已有目录时保留源文件名，支持 pull 到 ./，继续执行覆盖确认与并发检查。
- 本机项目直接使用 tmux、本地 TCP 转发和经过暂存校验的文件复制。
