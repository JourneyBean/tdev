# v0.0.2

提供可直接使用的 macOS/Linux 二进制包和一键安装入口。

```sh
curl -fsSL https://github.com/JourneyBean/tdev/releases/latest/download/install.sh | sh
```

- Linux/macOS，各提供 amd64 与 arm64 的独立二进制及 `.tar.gz` 包。
- 安装脚本自动识别平台，校验内置 SHA-256 和 Ed25519 签名 manifest，再原子安装到 `~/.local/bin/tdev`。
- 正式安装脚本内置发布公钥与四个平台的校验值，普通安装仅需要 curl、系统 shell 和 SHA-256 工具。
- 默认配置当前 shell 的 PATH，支持 bash、zsh、fish 和 POSIX sh；已有启动文件先备份，重复执行保持幂等。
- `--no-modify-path` 跳过 PATH 配置，`tdev path --write` 可单独设置。
- 支持带空格、UTF-8 与 shell 特殊字符的安装目录，保留原有 dotfile 的内容、权限及符号链接。

安装完成后打开新终端，或执行安装器输出的 PATH 命令。安装器无法更改父 shell 的当前环境。

下载链接、手动安装与签名信息见[安装与下载](../installation.md)。
