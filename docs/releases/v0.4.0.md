# v0.4.0

统一安装状态与回滚管理，调整 tmux 会话命名，简化本机项目转发和临时会话列表。

- 安装收据与备份统一存放在 `${XDG_STATE_HOME:-~/.local/state}/tdev/installations/<安装目标路径的 SHA256>/`。旧收据及其引用的备份链在安装或回滚时自动校验迁移；安装目标各自独立，安装锁按目标共享。
- 重复安装相同二进制时保留原文件、修改时间和已有回滚链，按需恢复执行权限、更新可信公钥和下载源；内容变化时才创建新备份。
- 每个安装目标保留当前版本之前的两个版本，可连续回滚两次。成功安装或回滚后清理超出范围的安装器备份。
- 新建项目 tmux 会话使用 `tdev-project-<name>`。名称被其他会话占用时使用 `tdev-project-<UUID>`，UUID 去掉连字符；已有托管会话继续按项目 UUID 复用，保留原会话和连接。
- scratch 会话使用 `tdev-scratch-<name>`，省略名称时自动生成 UUID。`ls` 每个 scratch 会话显示一行。
- `open local/<project>` 自动跳过目标为 `localhost`、`127.0.0.1` 和 `::1` 的转发，适用于 L/R 方向。显式 `forward` 命令及远端项目沿用已有行为。
- 增加安装幂等、状态迁移、历史备份裁剪、本机自动转发及新旧会话命名回归。GitHub Actions 执行真实 SSH/tmux 竞态测试、四平台签名发布及公开附件下载验证。

机器协议、配置 schema 均保持为 1，沿用现有安装签名公钥。回退到仅支持旧收据路径的历史版本后，使用新版安装脚本再次升级。macOS 原生交互、真实跨文件系统状态迁移及中断恢复等覆盖限制见[验收记录](../acceptance.md)。
