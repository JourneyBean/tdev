# v0.2.0

增加诊断日志，修复 zsh 登录 shell 下的远端目录补全。

- 增加 GitLab CI：受保护的版本 tag 通过测试后自动构建签名包、上传 Generic Package Registry 并创建 Release。GitLab 安装包内置项目下载及升级来源，配置见 [GitLab CI 发布](../gitlab-release.md)。
- 失败操作自动写入配置根下的 logs/diagnostics.jsonl；--debug 增加成功命令与 SSH/API 请求记录。
- 目录补全失败时显示错误类别和日志位置。日志包含耗时、协议错误码、原因类别及可用的进程退出码，使用私有权限和大小轮转。
- 日志排除命令参数、目录输入、环境变量、凭据与原始远端输出。未知原因记为 operation_failed。
- 目录枚举脚本显式通过 sh -c 执行，空目录及未匹配的隐藏目录通配符可在 zsh 登录环境下正常处理。更新客户端即可获得修复。
- 协议版本、配置 schema 和 capability 要求沿用 v0.1.0。

项目命令与 API 的变更见 [v0.1.0](v0.1.0.md)。
