# v0.10.0

## Web 路由与 HTTPS

- 运行 `tdev web setup` 设置客户端代理，或运行 `tdev web setup dev/demo` 为本机或远端项目添加、修改、删除 Web 路由。向导在保存前显示修改预览。
- 短主机名 `demo` 默认展开为 `demo.tdev.localhost`，后缀由客户端配置。已有完整 `*.localhost` 域名沿用原值。
- HTTP 默认端口从 17890 改为 24880，HTTPS 默认端口为 24881。显式设置的 HTTP 端口继续生效。升级后可通过 `client.http.port` 保留旧入口端口。
- HTTPS 入口按域名提供自签名证书，浏览器通常会提示证书不受信任。路由可通过 `target_scheme: https` 使用 HTTPS 上游，代理跳过上游证书校验。两种入口均支持 WebSocket，路由 JSON 增加 `https_url`。

配置与升级后的路由启停方式见 [Web 服务转发](../web-services.md)。

## SSH 和工作项列表

- 首次 `setup` 复用已认证的 SSH 连接上传安装包。项目 TCP 转发、Web 隧道和 SCP 可共享控制连接。认证失败显示 `unauthorized`，交互式 `open` 重新认证后，等待认证的项目转发会恢复。
- 顶层 `tdev ls --all` 包含未启动项目，可与 `--server` 组合。`--include-inactive` 继续可用。默认 `tdev ls` 查询本机和所有已配置远端的活跃工作项。客户端缺少 tmux 时仍可查询其他资源和远端项目。
- 内置 AI skill 只保留操作约定和 JSON 接口说明，具体参数由当前版本的 `--help` 提供。

## 升级

升级客户端以及使用新 Web 路由格式的项目所在机器。运行中的客户端 daemon 随升级刷新，也可用 `tdev daemon restart` 手动刷新。

```sh
tdev upgrade -y
tdev upgrade --remote dev -y
```

验收结果与平台覆盖见 [验收记录](../acceptance.md)。
