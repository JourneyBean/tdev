# v0.0.1

tdev 首个版本，通过系统 OpenSSH 和 tmux 组织远端项目工作环境。

- 项目配置、会话恢复、窗口保存及本地/远端机器接口。
- 独立 TCP 转发、转发重连和终端重连；重试次数、间隔可配置，重连中 Ctrl-C 可退出。
- 文件上传/下载，包含暂存、校验、覆盖确认和并发变更检测。
- SSHFS 挂载、复用、占用检查及卸载；macOS 元数据保护。
- 四平台二进制、Ed25519 签名发布、安装、升级与回滚。
- UTF-8、中文、日文、韩文、emoji，以及 macOS 文件名规范化兼容性验证。

目标平台为 Linux/macOS 的 amd64、arm64。原生执行已覆盖 Linux amd64 与
macOS arm64；另外两种架构完成交叉构建。Go 仅为构建依赖。

完整验证结果见[验收记录](../acceptance.md)。Linux 真实 FUSE 挂载、GUI 剪贴板、
鼠标和输入法交互尚未实测；HTTP 域名代理留待后续版本。

首次安装必须通过独立可信渠道确认发布公钥，再运行安装器。升级保留备份，
可使用 `tdev rollback` 回退；不会停止现有 tmux 会话。
