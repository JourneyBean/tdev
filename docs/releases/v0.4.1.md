# v0.4.1

修复升级回滚与交互 shell 启动命令，优化未运行项目的状态文案。

- 修复旧安装器在二进制被外部替换后留下过期备份收据，导致后续安装、升级或回滚失败的问题。迁移时校验备份内容与安装目标，在过期收据处截断回滚链，保留原始备份和历史文件。新安装仅关联与实际备份内容一致的收据。
- pane 使用 tmux 的默认交互 shell 和启动配置，初始化后执行声明命令，支持初始化脚本中定义的工具。命令结束后可继续使用 shell；显式 `exit` 结束 shell 时保留 pane 输出与退出状态。适用于单窗口与分屏布局。
- `ls` 文本输出将尚未启动或已停止的项目显示为 `inactive`；JSON、服务端状态与缓存继续使用 `missing`。

机器协议、配置 schema 均保持为 1，沿用现有安装签名公钥。环境覆盖与人工验收限制见[验收记录](../acceptance.md)。
